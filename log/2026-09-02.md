  append a new section instead of editing a protected one. Fixed by declaring the whole file
  read-only to sessions at the top, and listing that status among the protected limits.
- [medium] No audit trail: nothing required the review verdict to be recorded, so a returning owner

- [low] README omitted `RUNBOOK.md` and still described `OWNER.md` as "optional, human-authored" —
