# Idea: Vendor security questionnaire autofill assistant

## Concept

A tool for small B2B SaaS companies that stores past questionnaire answers (SOC2-adjacent,
InfoSec, data-handling) and auto-drafts responses to new procurement security questionnaires from
prospects/enterprise customers, using the stored answer library as source material.

## Target user

Small B2B SaaS vendors (roughly 2-50 people) closing their first enterprise deals, with no
dedicated compliance hire — usually a founder, sales engineer, or single security-adjacent
engineer answering these by hand.

## Problem

Enterprise buyers gate procurement on a security questionnaire (50-100+ questions), and small
vendors have to answer it from scratch or from scattered past answers, repeatedly, without anyone
whose job it is to own the process.

## Why now

No specific regulatory or platform trigger identified — this is a persistent, not newly created,
pain point that has existed for years (see first-person evidence in `VALIDATION.md`, dated
2019-2023).
